## 欄位與去識別方式

去識別不是匿名保證。原文、去識別樣本、原始欄名及自由文字模板都視為私人衍生資料，只在本機隔離區處理；不貼聊天、不傳給模型、NAS 任務或 Git。不能改標 `synthetic=True` 餵入現有合成入口。

| 資料 | 本機處理與保留語意 |
| --- | --- |
| 結構 | 原始欄名／順序、分隔符、quote／escape、BOM／編碼／換行保留在本機；先辨識已知欄位，未知 schema 拒絕，不以猜字串方式找私人值 |
| 成敗、服務／事件類型 | 只以本機人工核對的映射識別 DSM success／failure；未識別為 unknown。自由文字結果不能猜成確定成功／失敗 |
| 帳號、IP、主機／設備、record ID | 本包獨立隨機金鑰及欄位 domain 分離的 HMAC-SHA256 產生 opaque 參照；金鑰／映射不外送。相同原值同域相同、不同域不同，不跨包追蹤 |
| 型態必要的欄位 | 原 IP／數字 ID 先在本機完成語法判別；如需型態一致的衍生 fixture，用本包唯一的人工測試值重新建造，明示 artificial，不能假稱保留原值／原始長度 |
| 時間 | 所有列採同一平移量，保留相對間隔、原格式及逐列 offset，標 `shifted`；平移量只留本機。無 offset／DST 模糊／未知時鐘誤差不補值；不宣稱真實事件時刻或排序可信 |
| 穩定紀錄身分 | 只有實際確認來源 ID 的唯一性／範圍後才作 record identity；沒有就只用本次匯入行序參照，明示不能跨匯出精準去重，不用秒級分桶或內容 hash 假造 ID |
| 自由文字及非必要欄位 | token／cookie／session、密碼、分享名、私人路徑、query/body 等不保留。未知文字以固定 placeholder 取代並標語意未驗；原模板不得回傳 agent |
| CSV／惡意內容 | 用欄位級 CSV 解析與序列化，不做整行 replace，不開試算表、不執行公式／HTML／命令；任何安全中和或重新序列化都記錄為轉換，不能拿來證明原始 bytes 完全相同 |

給開發 agent 的輸出限固定白名單：本機核實的產品版本字串（嚴格版本格式）、預定語系／編碼／分隔符枚舉、列數／欄數、offset／BOM／多行是否存在、已知映射枚舉、成功／失敗／unknown 計數、固定錯誤碼及通過／未驗項目。不得包含原欄名、樣本列、HMAC 值、原路徑、原例外或任意自由文字。白名單以外不輸出，未知保留 unknown。

期限是提案，尚未設定、排程或刪除任何檔案。若無合適的既有私有非同步目錄，不改 ACL／帳戶或同步設定，停止。普通刪除不保證磁碟安全抹除；到期未確認刪除即標 retention_unconfirmed，不再使用該包，也不聲稱已刪除。既有 NAS 原始日誌完全不在刪除範圍。

樣本完整性 SHA-256 只留本機回條，分開標 raw artifact 與 transformed artifact；hash 不證明來源可信或無缺漏。agent 摘要只引用本次無私密內容的方案 ID，不能用 hash 把私人內容變成可公開證據。
