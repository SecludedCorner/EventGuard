# EventGuard 維護目標

更新：2026-10-23；本批基底befeed79d4ec8c5d5541ff473e11c5cf3b8af872。使用者最新定位是**資安情報中心**：人類與agent經EventGuard取得觀察、理解事件、執行允許的操作，並在產品內看到正在做什麼及結果。沿用feature與資料，不reset/clean；既有研究目錄保留。

## 本輪實作範圍

- 沿用七來源、耐久事件、事件綁定查證與報告；不新增另一套控制器或事件佇列。
- 共享operator加入activity，GUI呈現人類／MCP操作進度與歷史；先保存操作意圖，結束記錄結果，未確認不能寫成功。
- 依已批准範圍接正式專案MCP，保留合成入口；須區分設定已加入、當前聊天已載入、實際呼叫成功三種證據。
- 採納GitHub盤點中適用的輸出容量與JSON解析防護，不下載或執行25個外部掃描器。
- 功能集中驗證後本地提交；具體命令、失敗、修正與通過範圍以 [EVIDENCE](EVIDENCE.md) 為唯一測試數來源。

## 完成與待驗證分開

正常監看由程式等待，不因模型額度停止。人類能獨立操作；agent只使用相同的型別化能力，不能給自己開權限。操作紀錄不收集聊天思考、任意shell／檔案操作或私人原文；它也不是抗同使用者竄改的安全稽核帳本。

本聊天先前已真正接收合成事件；**閒置時自動喚醒同一聊天仍未接通**，不得以另一個CLI或定時模型輪詢代替。外部漏洞情報匯入、跨主機整合、24小時soak、Phase7狀態注入及實際OS重開機恢復仍不是已驗證能力。
